# Revisión de traducción — source-2 y source-3a

Se completaron 342 unidades de `source-2.json` y 171 de `source-3a.json` en inglés estadounidense y español latinoamericano con `tú`. Los cuatro catálogos se revisaron con una lectura simulada para personas adultas principiantes, de acuerdo con el público y las prácticas descritos en el currículo.

La revisión abarcó las lecciones 6 a 15: mapa de significado, jerarquía y contraste, fotografía, comparación de propuestas con IA, generación y comparación de imágenes, aplicaciones, guía de uso y revisión del proyecto. Se aclaró que las asociaciones de color son hipótesis contextuales; que las imágenes generadas son ilustrativas y no prueban servicios, investigación ni pruebas con público; y que una práctica de generación solo queda completa con un archivo realmente creado, guardado y revisado. Se mantuvieron opciones de evaluación con longitudes y niveles de detalle comparables.

Los campos entre `&lt;` y `&gt;` que contienen instrucciones para la persona se tradujeron; se conservaron los delimitadores y las etiquetas HTML. Se preservaron cifras, enlaces, atributos y nombres propios, así como el nombre ficticio Fio Claro. No se inventaron datos reales de contacto ni resultados de investigación.

Límites: la lectura fue simulada, no una prueba con estudiantes ni con participantes de investigación. No se generaron imágenes durante esta traducción ni se verificó el resultado de un generador externo. No se usaron red, APIs ni servicios externos.
