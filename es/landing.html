El caso Fio Claro

Isa, diseñadora de 35 años, y Célia, costurera de 57 años, definen el estilo de un taller ficticio de reparaciones visibles. Las imágenes de Codex son ilustraciones; no afirman servicios ni resultados reales.

Ver imágenes didácticas y prompts. El proyecto final incluye una ficha de marca, tres pilares, un panel con seis referencias, un mapa con seis elementos, dos imágenes comparadas, tres aplicaciones y una guía de uso.

Cómo estudiar

Lee en sesiones de quince minutos y completa las prácticas. Para producir todo, reserva 7–11 horas, además de las esperas de generación y las conversaciones con el público. No se prometen ventas ni una reacción emocional automática.

Debes saber guardar archivos y usar una aplicación de notas, documentos o presentaciones. Para generar imágenes necesitas acceso a un generador. Revisa las condiciones de tu cuenta. Los ejercicios sin un archivo producido quedan pendientes.

El progreso queda en este navegador. Usa el panel de recorrido para guardar una copia. Las páginas incluyen texto, ejemplos y actividades; no son videoclases grabadas.

Para quién es

Creadores y pequeños negocios

Para quienes quieren justificar sus decisiones y mantener coherencia entre piezas.

Conocimientos necesarios

Uso básico de archivos y un editor que ya conozcas. No requiere programación.
